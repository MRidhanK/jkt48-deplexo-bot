📱 MOBILE SYNC

JKT48 → Ticket Radar

HP membaca My Tickets dari halaman JKT48 yang sedang login, lalu mengirim data tiket dan access token dari /api/auth/session ke Radar milikmu sendiri, sehingga tombol Fetch di dashboard langsung bisa dipakai tanpa tempel session manual. Cookie tidak dikirim.
Kode pairing
-
Kode berlaku 10 menit sampai sync pertama; setelah itu otomatis diperpanjang selama sync berjalan. Kode tertanam di bookmarklet ini.
1
Pasang bookmark
Buat bookmark bernama 🎟️ Radar Sync, lalu ganti URL bookmark dengan kode di bawah.
2
Login ke JKT48 di HP
Buka https://jkt48.com memakai browser yang sama dan pastikan akun sudah login.
3
Jalankan Radar Sync
Jalankan bookmark saat halaman JKT48 terbuka. Sync pertama mengambil seluruh halaman My Tickets, kemudian mengulang setiap 60 detik selama tab JKT48 tetap terbuka.
Android Chrome: buat/edit bookmark dan masukkan kode javascript: ke URL bookmark. iPhone: Safari + Shortcuts memiliki aksi Run JavaScript on Webpage untuk halaman Safari aktif.
